Fibonacci Program in Python

About

This project contains a beginner-level Python program that prints a specified number of terms from the Fibonacci sequence.

How to Run

1. Make sure Python is installed on your computer.
2. Open a terminal in the folder containing fibonacci.py.
3. Run the command:

python fibonacci.py

4. Enter the number of terms when prompted.

Learning Objectives

* Understand Python variables.
* Practise loops.
* Learn how to update multiple variables.
* Display a sequence of numbers using print().
